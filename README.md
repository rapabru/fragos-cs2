# 🎯 FragOS — CS2 Adaptive Academy & Performance Analytics

> **Ecosistema de Entrenamiento, Diagnóstico Leetify y Vault Táctico para Counter-Strike 2**

FragOS es una plataforma web desarrollada en **Next.js 15 (Turbopack)**, **Tailwind CSS v4** y **Recharts**, diseñada para transformar datos de rendimiento en rutinas de práctica adaptativas y guías tácticas en tiempo real.

---

## 🚀 Características Principales

* **📊 Diagnóstico & Matriz de Competencias tipo Leetify:**
  * Radar comparativo: Tu Rendimiento vs Promedio Premier vs Nivel 10 FACEIT.
  * Comparador de evolución por períodos (Win Rate, K/D, ADR, Opening Duels, DPR).
  * Detección automática de debilidades críticas y fortalezas.
* **📈 Historial Forense de Partidas Premier:**
  * Registro cronológico con ratings de Leetify, CS Rating de Valve, K/D/A y notas de hito.
* **⏱️ Generador de Rutinas Adaptativas (15 a 60 min):**
  * Prescripción dividida en 3 fases: Calentamiento & Primer Disparo, Corrección de Falencias mecánicas (Prefire), y Transferencia en Deathmatch FFA.
  * Comandos de consola rápidos para mapas de Steam Workshop.
* **🗺️ Vault de Lineups & Tácticas por Mapa (Active Duty 2026):**
  * Smokes, flashes, molotovs y executes para los 7 mapas competitivos: *Mirage, Dust 2, Inferno, Anubis, Nuke, Ancient y Vertigo*.
  * Filtro interactivo por mapa y enlaces a clips de referencia.
* **💬 Integración con Servidor Discord (Escuela CS):**
  * Sincronización con roles automáticos y 12 canales temáticos de estrategia y entrenamiento.

---

## 🛠️ Stack Tecnológico

* **Framework:** Next.js 15 (App Router, Turbopack)
* **Lenguaje:** TypeScript
* **Estilos:** Tailwind CSS v4 con paleta dark mode esports (Slate, Cyan, Emerald, Rose)
* **Gráficos & Visualización:** Recharts (RadarChart, ResponsiveContainer)
* **Iconografía:** Lucide React
* **Deployment:** Vercel

---

## 💻 Desarrollo Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build

# Iniciar build de producción
npm run start
```
